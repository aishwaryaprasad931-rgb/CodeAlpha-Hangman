# CodeAlpha Hangman Game 🎮

A simple text-based Hangman Game developed using Python as part of my CodeAlpha Python Programming Internship.

## 📌 About the Project

This is a console-based Hangman game where the player tries to guess a randomly selected word one letter at a time.

The game provides a maximum of 6 incorrect guesses. The player wins by guessing all the letters before using all the available chances.

## ✨ Features

- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Displays the progress of the word
- Tracks already guessed letters
- Allows 6 incorrect guesses
- Shows the final result
- Simple and beginner-friendly console interface

## 🛠️ Technologies Used

- Python
- `random` module
- Lists
- Strings
- Loops
- Conditional statements
- User input
